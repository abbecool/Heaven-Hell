# Forger: The Hollow King — Story Lore

This is the working lore reference for the project. **Forger: The Hollow King** is the current working title; *Heaven and Hell* is the former title.

## How to Use This Folder

Read [Canon](canon/README.md) for established world and story facts. It is the only area that may be treated as in-world truth.

- `canon/`: settled facts. Each subject has one primary home.
- `design/`: intended experience and possible future content. These notes do not establish facts by themselves.
- `decisions/`: unresolved questions that need an explicit future decision.
- `archive/`: superseded source material. Do not use it to establish or override canon.

The current reading order is:

1. [Core Premise](canon/core-premise.md)
2. [History](canon/world/history.md) and [Magic Cycles](canon/world/magic-cycles.md)
3. [Geography](canon/world/geography.md), [Factions](canon/factions/), and [Characters](canon/characters/)
4. [Main Story Arc](canon/story/main-arc.md) and [Chapter 0: Awakening](canon/story/chapters/00-awakening.md)
5. [Possession](canon/systems/possession.md)

## Design References

- [Possession and Quest Design](design/possession-and-quest-design.md): working direction for freely switching hosts, host progression, and quest structure.

## Status Language

- **Canon**: established and usable as fact.
- **Design direction**: an intended gameplay or narrative approach; it can change.
- **Exploratory**: a possible future idea, not a current fact.
- **Open question**: deliberately undecided.
- **Archived**: superseded information retained only for reference.

## Writing Rules

- Add a fact to its canonical subject file once, then link to it elsewhere.
- Put alternate ideas in `design/` and decisions still needing an answer in `decisions/`.
- Use [Knowledge Matrix](canon/reference/knowledge-matrix.md) for what each faction believes. A faction's belief is not automatically objective truth.
- Do not use any file in `archive/` as current lore.
